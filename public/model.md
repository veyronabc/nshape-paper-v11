# N 字二板量化模型 v1.0

## 一、模型定位

这是一个**短线事件驱动模型**，不是全天候选股模型。

- 只做主板
- 只做 10:45 后封板的首板
- 只做首板后的 N 字回调
- 只做 09:45 前弱转强的二板
- 靠连板尾部收益获利

## 二、股票池

- 沪深主板：600/601/603/605/000/001/002/003
- 剔除 ST、退市、上市不足 250 个交易日的股票
- 首板当日成交额 ≥ 5000 万
- 首板前 20 日均成交额 ≥ 8000 万

## 三、分支 A：强市顺势

| 条件 | 规则 |
|---|---|
| 大盘 | 沪深300 在 MA20 上方 |
| 首板前趋势 | 前 20 日涨幅 >30% |
| 首板 | 10:45 后封板，开板 1–2 次 |
| 回调 | 单阳不破，小阳 ≤1 根 |
| 买点 | 09:45 前涨超 3%，高开 3%–5% |
| 卖出 | 封二板后持有连续板，断板日收盘卖 |

## 四、分支 B：弱市反转

| 条件 | 规则 |
|---|---|
| 大盘 | 沪深300 在 MA20 下方 |
| 首板前趋势 | 前 20 日跌幅 <-5% |
| 首板前量能 | 5 日均量 / 20 日均量 <0.8 |
| 首板 | 10:45 后封板 |
| 回调 | 单阳不破，小阳 ≤1 根 |
| 买点 | 09:45 前涨超 3%，高开 3%–5% |
| 卖出 | 封二板后持有连续板，断板日收盘卖 |

## 五、单阳不破

- 以首板这根涨停阳线为“单阳”
- 首板到买点之间允许收阳
- 回调期间最低价不能跌破首板最低价
- 更强口径：不跌破首板开盘价

## 六、买点

1. 首板后第 2 或第 3 个交易日
2. 09:30–09:45 内，价格较前收上涨超过 3%
3. 开盘已高于 3%：按开盘价买入
4. 开盘低于 3%、盘中触发：按 +3% 触发价买入
5. 高开超过 5%：放弃

## 七、卖点

### 未封二板

- 买入日收盘卖出

### 封二板

- 继续持有
- 后续每天收盘封板则继续持有
- 第一次断板，按断板日收盘卖出

## 八、仓位管理

- 单笔目标仓位：当前权益的 **20%**
- 最多同时持有 **5 笔**
- 单日最多新开 **3 笔**
- 预留至少 5% 现金
- 同一股票 5 个交易日内不重复开仓

> 评分只用于同一天多个信号时的优先级排序，不按评分加仓。  
> 因为评分分档回测没有表现出单调性，按评分加仓属于过度拟合。

## 九、风控

- 大盘环境不符合分支条件：不做
- 高开 >5%：不做
- 回调小阳 ≥2 根：不做
- 跌破首板最低价：不做
- 单笔亏损达到 -8%：收盘止损
- 连续 3 笔亏损：暂停 3 个交易日

## 十一、仓位敏感性

| 单笔仓位 | 最终资金 | 总收益 | 最大回撤 |
|---:|---:|---:|---:|
| 10% | 115,790 | +15.79% | 3.49% |
| **20%** | **133,493** | **+33.49%** | **6.87%** |
| 30% | 153,258 | +53.26% | 10.13% |
| 50% | 201,299 | +101.30% | 16.61% |

建议先用 **10%–20%** 仓位验证，不建议直接上 50%。

## 十二、模型局限

1. 参数为样本内筛选，存在过拟合风险
2. 分支 B 只有 17 笔交易，统计稳定性不足
3. 未模拟涨停排队、封单不足、炸板
4. 假设 09:45 触发价可以成交
5. 使用不复权日线
6. 历史回测不代表未来收益
